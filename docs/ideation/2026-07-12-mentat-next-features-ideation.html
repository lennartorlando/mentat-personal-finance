Ideation: Mentat next features

A ranked set of feature directions for turning Mentat from a secure balance-export CLI into a private system that helps people understand their full financial position and its implications.

Grounding context

Current product reality

Mentat has a security-hardened AqBanking/FinTS CLI for user setup, account discovery and balance CSV export. It has no local ledger, transaction ingestion, tagging, reports or dashboard yet.

Strategy constraint

The primary value is not aggregation alone. Mentat must turn distributed European finance data into understandable changes and implications while staying local-first and avoiding financial actions.

Existing product direction

The current product plan already commits to a canonical local ledger, CSV fallback imports, deterministic tagging before LLM help, factual reports before narrative, and a read-only dashboard only after those contracts stabilize.

External signal

Established local finance tools treat imports, duplicate handling and user-owned rules as core product capability, not plumbing. That reinforces a trustworthy data loop before an insight surface.

01 · Monthly insight and implications

Monthly Financial Close

Confidence 92%Complexity High

A deliberate monthly workflow: sync or import available sources, surface missing or stale ones, reconcile the snapshot, and produce a factual summary of net worth, cash, income, expenses and meaningful changes. It replaces the monthly spreadsheet ritual with an explicit moment of financial clarity, not an always-on pile of charts.

Basis
direct: The strategy's primary user currently needs a complete overview before investments; the product plan names a private monthly report as the first end-to-end value loop.
Rationale
It makes the intended user value testable: Mentat either produces a trustworthy monthly overview or clearly says what is missing.
Downsides
It depends on the ledger, source ingestion and confidence checks below. The right first slice should remain factual and local, without an LLM narrative.

02 · Trusted financial truth

Verified Local Ledger

Confidence 96%Complexity High

Create the canonical local record of accounts, dated balances, transactions, holdings, imports and provenance. Every record retains its source identity and import timestamp; duplicate detection, transfer matching and corrections are explicit rather than hidden in exported CSVs.

Basis
direct: The current CLI appends balance rows to CSV, while the product plan explicitly makes a normalized ledger the source of truth for all connectors and surfaces.
Rationale
It is the prerequisite for showing one total without double-counting, explaining any movement, or offering identical facts to a person and an agent.
Downsides
It is foundational work with little immediate visual payoff. Scope must stay file-backed and auditable before choosing a database or server.

03 · Heterogeneous data intake

Import Profile Studio

Confidence 90%Complexity Medium

Turn each broker, app-bank or exchange export into a repeatable local import profile: map columns once, preview normalized rows, identify duplicates, and save the profile locally. The product should report what it recognized, what it skipped and why, rather than making users write a custom parser for every CSV.

Basis
direct + external: The plan treats CSV adapters as first-class coverage; Actual Budget's import flow emphasizes field mapping and duplicate avoidance for financial files.
Rationale
It covers the banks and brokers that will never be reached reliably through one live integration, while preserving the local-first boundary.
Downsides
Import formats drift. Profiles need clear validation, synthetic fixtures and a non-destructive preview mode.

04 · Trusted financial truth

Data Confidence Map

Confidence 88%Complexity Medium

Show which expected accounts and depots are current, stale, missing, partially imported or awaiting review. Every dashboard total and report section carries an understandable coverage signal, so Mentat never silently presents an incomplete net-worth number as complete.

Basis
direct: The strategy measures successful, current account and depot coverage; the product plan requires freshness and source confidence in monthly reporting.
Rationale
Trust is created as much by showing what Mentat does not know as by visualizing what it does.
Downsides
It requires a user-declared source inventory and clear semantics for "current" across sources with different refresh capabilities.

05 · Monthly insight and implications

Explain the Delta

Confidence 86%Complexity Medium

For every meaningful month-over-month change, let the user trace the result back to the accounts, movements, prices or imports that caused it. The first version is factual: "cash changed because of these booked flows" and "portfolio value changed because of these positions"; narrative generation remains optional and never invents the evidence.

Basis
direct: Mentat's strategy differentiates on implications, while the product plan explicitly separates factual metrics from optional LLM narrative and requires provenance.
Rationale
This is the shortest route from a number to an informed conversation or decision, and it is more differentiated than another aggregate chart.
Downsides
Attribution gets nuanced when a period has transfers, market movement and partial data. The UI must preserve uncertainty instead of forcing a single cause.

06 · Explainable automation

Review Inbox and Local Category Memory

Confidence 84%Complexity Medium

Place new, unclassified, conflicting or suspicious transactions into one review queue. When a user corrects a merchant or category, Mentat proposes a deterministic local rule, previews its future effect and records the rule's provenance; no classification mutates silently.

Basis
direct + external: The plan already calls for deterministic rules and explicit review. Actual Budget demonstrates that user-owned rules can learn from repeated category and payee corrections.
Rationale
This turns manual cleanup into compounding private automation while preserving the trust boundary needed for financial data.
Downsides
Rule precedence and overrides can become confusing. The first version should support a small, inspectable rule vocabulary and dry runs.

07 · Monthly insight and implications

Personal Decision Guardrails

Confidence 72%Complexity Medium

Let people define their own cash floor, reserve, allocation bands, recurring commitments or planned investment amount. Mentat then reports distance to those self-authored guardrails and offers scenarios such as "what remains after the planned transfer" without selecting investments or initiating actions.

Basis
reasoned: The strategy's user seeks a complete overview before investments; a user-defined constraint converts that overview into a concrete, non-advisory implication.
Rationale
It gives the insight layer a personal purpose without crossing into financial recommendations or automated execution.
Downsides
Scenarios can be mistaken for advice. Language must be strictly descriptive, assumptions visible, and defaults conservative.
